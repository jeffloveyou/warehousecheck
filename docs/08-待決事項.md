# 待決事項與決策清單

**原則：** 「待決」項目尚未由使用者明確決定，AI Agent 不得將建議預設寫成已批准規格。能先做不受影響的小步 PoC 時，不要阻擋整個專案。已決項目以對應 ADR 為準。
