# 系統操作手冊 v1.0

> 給現場使用者看的操作說明，依角色分節。網址：`https://192.168.0.86:5443`。
> 維運（備份、換版、故障）見 `docs/12`；上線與試運轉的步驟見 `docs/15`。

## 0. 共通
### 0.1 角色
| 角色 | 可以做的事 |
|---|---|
| 作業員 | 建立進倉、出倉、移庫單並確認過帳；建立期初單；盤點計數；手動預留；提出新物料；替物料增加俗稱與關鍵字 |
| 倉庫主管 | 作業員能做的事，加上：核准單據與期初單、開始盤點與核准盤差、維護倉庫與儲位、印儲位標籤、刪除倉庫 |
| 物料管理員 | 核准新物料、修改物料、維護分類與單位、負庫存設定；提出新物料時可以「自動核准」 |
| 系統管理員 | 帳號、系統設定、操作日誌、系統狀態 |
| 只讀 | 只能查詢（物料、庫存、單據） |

- 一個帳號可以有多個角色。
- 帳號可以限制只能在某些倉庫作業。被限制的人看得到其他倉庫，但不能在那些倉庫作業。

### 0.2 登入
- 第一次登入一定要改密碼。
- **記住我**：勾選後 14 天內不必重新登入，每次使用都會自動延長。天數由系統管理員設定。
  - **公用電腦請不要勾選。**
  - 帳號被停用或改了角色後，最慢 5 分鐘就會被登出。
- 登出只會登出這台裝置。

### 0.3 找物料（沒有標籤也能用）
- 在「搜尋」或明細輸入區的物料欄輸入以下任何一種都可以：
  - 料號，例如 `EL-000125`，大小寫、全形都可以。
  - 品名、規格、型號。
  - 俗稱，也就是專屬別名或共用關鍵字。
- 結果會列出料號與完整規格。**一定要自己點選正確的那一筆**，系統不會自動幫你選。
- 搜不到時，可以在搜尋結果頁把這個詞加到正確的物料上，下次就搜得到。

### 0.4 掃碼
- 電腦接 USB 條碼槍，把游標放在掃碼框，掃描即可。
- 手機在明細輸入區或「掃碼」頁按相機按鈕，第一次會詢問相機權限。
- 預留、盤點、搜尋、庫存查詢、物料條碼等表單上方有「相機掃碼」按鈕：
  - 相機會一直開著，可以連續掃；用完按「停止相機」。
  - 掃到的內容填進目前點選的欄位，結果顯示在該欄下方，接著自動跳到下一個空白欄。
  - 掃到的不是這一欄的資料（例如在儲位欄掃到物料），不會填入，請先點要填的欄位再掃。
  - 按「記錄」「建立」送出後，相機會自動重新打開。
- 盤點、建立預留可以選「相機數量方式」：手動輸入、帶入包裝量（外箱條碼帶入一箱的數量）、逐件累加（同一物料每掃一次加一）。逐件累加時掃到別的物料不會填，要先按記錄。
- 相機可以讀 QR 與包裝上的一維條碼（EAN、UPC、Code 128、Code 39 等），不必選碼制。
  - 畫面上同時有好幾個條碼時不會填值，請只對準一個。
  - 用相機掃不會自動送出表單，確認內容後再自己按送出。
- 系統認得以下幾種：
  - 儲位 QR：`WH:LOC:…`。
  - 料號，或物料 QR：`WH:ITEM:…`。
  - 登錄過的原廠條碼。
  - 專屬別名。
- 掃到不認得的條碼時，會改用搜尋，列出候選讓你點選。

### 0.5 常用設定會跟著帳號
明細輸入區的加入方式、欄位開關、靜音，以及上次用的倉庫，換電腦或手機登入時都一樣。

## 1. 作業員
### 1.1 進倉、出倉、移庫
1. 選單「進出倉單」→ 選類型與倉庫 →「建立單據」。系統會預選你上次用的倉庫。
2. 在**明細輸入區**依提示填寫，順序不拘：
   - **進倉**：物料 →（批號／序號）→ 儲位 → 數量。
   - **出倉**：物料 → 來源儲位（清單會先列出有庫存的儲位與數量）→（批號，清單會先列快到期的）→ 數量。
   - **移庫**：物料 → 來源儲位 → 目的儲位 →（批號）→ 數量。
   - 儲位欄可以打儲位碼、區或架，再從下拉清單點選。
3. 加入方式在明細輸入區右上角設定：
   - **手動**（預設）：欄位都填好後游標會跳到數量，按 Enter 加入。
   - **自動**：欄位都填好就用包裝數量直接加入。
   - **逐件累加**：每掃一次就加一個包裝數量。
   - 序號物料一律每個序號一行。
4. 明細表可以勾選多行後一次刪除。
5. 按「**確認過帳**」後才會真的改變庫存。在這之前都只是草稿。
   - 如果系統設定開啟了審核，按鈕會是「送審」，要由倉庫主管核准。
6. 要修正已過帳的單：開那張單，按「建立沖銷單」。系統會產生一張方向相反的草稿，確認後就抵銷。
7. 可以「列印」或另存 PDF，也可以上傳附件，例如送貨單照片。

> 網路不穩時，按鈕可以放心再按一次。同一個操作不會被重複扣帳。

### 1.2 期初建帳
- 請照 `docs/15` 的步驟做。
- 畫面操作：選單「期初」→ 選倉庫 →「建立期初單」→ 加入明細 →「送出核准」。
  - 加入明細可以用明細輸入區，也可以「從 Excel 匯入明細」。
  - 沒有東西的儲位，勾選「確認為空」。

### 1.3 盤點計數
- 選單「盤點」→ 開啟主管建立的盤點單 → 逐行填實盤數量 →「記錄」。
- 都填完後按「送審」。
- 盲盤時看不到帳面數量，這是正常的。

### 1.4 提出新物料
1. 先搜尋，確定物料不存在。
2. 選單「物料」→「＋ 提出新物料」，填品名、分類、單位、追蹤模式。
   - 有原廠條碼的話，填在條碼列，可以填多個，也可以填外箱的包裝數量。
3. 系統若找到相似的物料會列出來，確認不是重複後再送出。
4. 送出後要等物料管理員核准，核准後才有正式料號，才能做進出倉。

## 2. 倉庫主管
- **核准單據**：開「送審」狀態的單據 →「核准並過帳」或「退回修改」。
  - 預設不能核准自己建立的單，系統設定可以開放。
- **期初單**：「核准並過帳」，這會成為庫存的第一筆紀錄。
- **盤點**：
  1. 「盤點」→「開始盤點（建立快照）」，選擇範圍。盤點期間不需要停止進出倉。
  2. 作業員送審後，主管會看到差異：快照、期間異動、計數當下的帳面、實盤、差異。
  3. 有疑問的行用「勾選的行退回重盤」。
  4. 沒有疑問就「核准（產生調整單）」，系統自動產生 `ADJ-` 調整單並過帳。
- **倉庫與儲位**：選單「倉庫」。
  - 新增或修改倉庫、儲位，也可以從 Excel 匯入儲位。
  - 儲位碼建議照「區-架-層」命名，例如 `A-01-03`。
- **儲位標籤**：「倉庫」→ 儲位清單 →「列印儲位標籤」，用一般印表機印在 A4 上（ADR-0020）。
- **刪除倉庫**：必須先把倉庫清空：結存全部為 0，也沒有未完成的單據、預留、盤點。
  - 從來沒用過的倉庫會整個刪除。
  - 用過的倉庫會改成「已刪除」，歷史紀錄照常顯示，之後可以還原。

## 3. 物料管理員
- **核准新物料**：開待核准的物料，確認不重複後按「核准並發料號」，或「退回修改」。
- **自己提出時**可以勾「自動核准」，送出就直接發料號。這個勾選會被記住。
- **從 Excel 匯入物料時**可以勾「匯入後自動核准」：
  - 沒有疑似重複的物料，確認後直接發料號；範本的「原廠條碼」欄會一起登錄（這一欄先設為「文字」格式再輸入）。
  - 結果頁有「疑似重複」警告的列維持待核准，之後逐筆確認。
- **修改物料**：
  - 分類一律不能改。
  - 已有交易的物料，要改基本單位或追蹤模式，必須系統管理員開啟設定，並且符合以下條件：
    - 勾選確認並寫原因。
    - 沒有未完成的單據、預留、盤點。
    - 改追蹤模式時，結存必須是 0。
- **原廠條碼與俗稱**：在物料頁的「搜尋索引」新增或停用。修改單也可以直接登錄條碼。
- **負庫存設定**：只有不追蹤批號、序號的物料可以設定，並且要設下限（ADR-0004）。
- 分類、單位、用途類型、往來對象的維護，在選單下方。

## 4. 系統管理員
- **帳號**（`/Admin/Users`）：新增、角色、可作業的倉庫、停用、重設密碼。
- **設定**（`/Settings`）：所有開關都在這裡，每次變更都會留下操作日誌。
  - 登入：記住我的天數。
  - 物料：有交易時可不可以改單位或追蹤模式。
  - 期初與盤點：可不可以自己核准。
  - 進出倉單：審核、欄位、明細欄位開關。
  - 資料保留期限。
- **操作日誌**（`/Admin/Audit`）：誰在什麼時間做了什麼，可以匯出。
- **系統狀態**（`/Admin/System`）：每天看一次，處理方式見 `docs/12` §2、§6。

## 5. 只讀
可以使用「搜尋」「物料」「庫存」「進出倉單」查詢，也可以匯出 Excel。不能建立或修改任何資料。

## 6. 常見訊息
| 訊息 | 意思 | 怎麼做 |
|---|---|---|
| 物料 … 的可用量不足：可用 X（已扣除預留），需要 Y | 庫存扣掉預留後不夠 | 查「庫存」確認數量與預留；需要時請主管處理 |
| 你沒有倉庫 … 的作業權限 | 帳號被限制只能在某些倉庫作業 | 請系統管理員調整帳號 |
| 資料已被他人修改，請重新載入後再操作 | 你開啟頁面之後，別人先改了 | 重新整理頁面後再操作 |
| 有其他人同時在處理相同的…，請稍後再試一次 | 剛好有其他人在處理同一個儲位、物料或單據 | 再按一次 |
| … 尚未核准或已拒絕，不能使用（或不能過帳） | 物料還在待核准 | 請物料管理員核准 |
