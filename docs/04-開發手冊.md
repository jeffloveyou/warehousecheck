# 開發手冊｜從第一天開始寫、隨功能成長

> 本文件是**持續更新的開發教材**。以下章節目前為基線及待完成事項，不應誤認系統已實作。每次完成程式變更都應同步更新對應章節，並在標題標出對應版本或 commit。

## 0. 文件用途與閱讀方式
本手冊持續記錄一個完整請求的路徑：`Web 頁面 → HTTP API → Application Service → Domain Rule → EF Core → PostgreSQL → 回傳結果`。接著了解 DTO、依賴注入、Migration、測試與日誌。看得懂比「AI 一次做完」重要。

## 1. 開發環境（M0 完成時補齊實際版本）
- OS：Windows 11；PowerShell 7；IDE：Visual Studio 或 VS Code（待選）。
- 工具：.NET 10 SDK、Git、PostgreSQL、資料庫管理工具；不以付費工具為必要前提。
- Git 初始操作教學：`git status`、`git diff`、`git add`、`git commit`、`git log`；提交訊息繁體中文。
- 解決方案建立、套件來源、NuGet 授權清單與指令必須記錄實際執行結果。

### 預計由使用者親自執行的指令（專案成立後核對路徑）
```powershell
# 讀懂各指令再執行；初次建立專案由 M0 任務提供確定版本
 dotnet --info
 dotnet restore .\Warehouse.sln
 dotnet build .\Warehouse.sln
 dotnet test .\Warehouse.sln
 git status
 git diff
```
**提示：** 以上是教學範例，不代表目前已有 `Warehouse.sln`。Agent 不得宣稱已執行。

## 2. 專案導覽（M0 更新）
- `Warehouse.Domain`：實體、值物件及不能破壞的業務規則。
- `Warehouse.Application`：使用案例與服務介面。
- `Warehouse.Infrastructure`：EF Core DbContext、Migration、Repositories。
- `Warehouse.Api`：路由、授權、驗證、錯誤處理。
- `Warehouse.Web`：查詢畫面、掃碼與 RWD UI。
- `Tests`：可重複驗證正確性的測試。

## 7. 每章固定格式
1. **功能要解決的問題**（用現場語言描述）。
2. **整體流程圖**（資料從哪裡進、去哪裡）。
3. **實際檔案路徑與類別**（不可只寫抽象範例）。
4. **重要程式碼逐段解說**（邏輯、設計取捨及陷阱）。
5. **資料庫表、約束及 Migration**。
6. **如何本機重現／操作**（PowerShell 指令及預期結果）。
7. **自動測試／人工驗收**。
8. **常見故障、錯誤訊息、查找步驟**。
9. **常見修改需求與操作說明**（不提供練習題）。
10. **本章關聯 Git commit、ADR、版本資訊**。

## 8. 版本控制與更新政策
- 文件與程式在同一個 Git repository，文件缺漏代表功能交付未完成。
- API 或資料庫結構改動時，手冊的檔案路徑與指令必須同步更新。
- 每個里程碑檢查一次手冊的指令、路徑及故障排查步驟是否仍符合實際程式，錯誤或過時內容必須修正。


## 9. 效能調校及舊電腦問題排查（M0–M7 持續更新）
- 如何用瀏覽器開發者工具判斷 Network、Memory、CPU 與前端載入阻塞。
- 如何查看 API 的處理時間、DB SQL 查詢、EF Core 日誌與 PostgreSQL `EXPLAIN (ANALYZE, BUFFERS)`（正式資料庫執行前須注意成本）。

- PoC 確定前端方案後，替換本文中通用 `Web` 名稱為實際頁面與檔案路徑。

## 10. Windows PC 部署與維護教學（M0 PoC 後填入實測指令）
- 正式運行的 OS、Runtime / Framework-dependent 或 Self-contained 版本、安裝與發布目錄。
- Windows Service／反向代理設定、憑證、服務帳號、環境變數、日誌及資料備份位置。
- 從 Git 取版到 PowerShell 發布的完整指令、可預期輸出、錯誤訊息及回復方法。
- 先以測試環境示範 A/B 切換、異常回滾，確認成功後才納入正式發布指令。

## 11. Linux NAS 部署與維護教學（取得 NAS 後實測）
- 實際 NAS 品牌／型號、CPU (`x64` 或 `arm64`)、RAM、OS 與相容容器環境。
- 容器或原生 .NET 執行的選擇理由、發布目標 RID、檔案儲存掛載及權限。
- HTTPS、網域、反向代理、PostgreSQL 連線、持久化資料、備份與日誌查看方式。
- 兩個 App 實例是否能同時啟動、健康檢查與切換操作、資源不足時的替代方案。

## 12. 線上更新與回滾教學（M0 PoC 後補實際配置）
- 應用 A/B 並行、反向代理的切換點、健康檢查、請求排空和停止舊版的理由。
- 如何識別目前版本、確認新版本已接流量、觀察錯誤率、確定沒有重複扣帳。
- 為何 PWA 舊資源可能繼續使用、如何通知使用者安全更新，而不清除未提交資料。
- PostgreSQL schema Expand → Migrate → Contract 變更順序、備份、回滾相容性。
- 發布／回滾指令、預期輸出、故障排查和更新紀錄皆須對應真實實作。
