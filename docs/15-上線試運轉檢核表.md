> 從「系統已架好」到「正式停用紙本」的現場步驟。使用者 2026-10-27 決定**沒有標籤機、不貼儲位與物料標籤**，本表以這種方式為準（ADR-0020）。

## 0. 沒有標籤機的作業方式（摘要）
| 對象 | 做法 |
|---|---|
| 有原廠條碼的物料（包裝上的 EAN 或廠商條碼） | 建檔或修改時登錄條碼（ADR-0023），之後直接掃包裝 |
| 沒有條碼的物料 | 在明細輸入區打料號、俗稱或規格，從清單點選。常用俗稱加成「專屬別名」 |
| 儲位（建議） | **不貼標籤，靠命名**：<br>・儲位碼照「區-架-層」命名，例如 `A-01-03`<br>・在層架上用麥克筆或手寫卡寫儲位碼<br>・作業時在儲位欄打 `A-01`，從下拉清單點選 |
| 儲位（日後想掃碼） | 用一般印表機把 `/Warehouses/Labels` 印在 A4 自黏標籤紙（3×8）上，或印在普通紙上用膠帶或卡套固定。不需要標籤機，也不必改資料 |
| 很小的倉庫 | 可以只建一個儲位，例如 `MAIN`。日後要細分時，用移庫單把物料移到新儲位 |

- 模糊搜尋的結果一定要人點選，系統不會自動當成明細。
- 沒有標籤時，精確性靠「點選時看清楚料號與規格」和 §4 的每日對帳。

## 2. 建立主檔
- [ ] **分類、單位**：物料管理員在選單下方維護。分類決定料號前綴，核准後不能改。
  - 核准時可以在「正式料號」欄自己指定料號（前綴要屬於這個分類或上層分類），空白就自動給流水號（D-32）。
  - 之後要對齊分類而改料號：系統管理員到「系統設定 → 物料」開啟「已核准的物料可改料號」，物料管理員在物料明細頁「變更料號」填新料號與原因。舊料號預設保留，舊標籤仍掃得到；已印的標籤請盡快換新。
- [ ] **倉庫與儲位**：倉庫主管在「倉庫」建立；儲位可以「從 Excel 匯入儲位」，必填欄位是儲位碼。
- [ ] **物料**：
  - 「物料」→「從 Excel 匯入」。
    - 必填欄位：品名、分類、基本單位、追蹤模式（不追蹤／批號／序號）。
    - 選填欄位：品牌、原廠型號、規格、原廠條碼（多個用頓號、逗號或分號分隔）。
    - ⚠️ 「原廠條碼」欄要先設為**文字**格式再輸入，否則 Excel 會吃掉前導零，系統會把那一列列為錯誤。
    - 帶條碼的物料建議每個檔案 500 列以內；出現「系統忙碌」時分成較小的檔案。
  - 匯入時會先試算，有任何一列錯誤就整批不匯入。一次最多 2,000 列。
  - **由物料管理員上傳並勾選「匯入後自動核准」**（D-31），確認後直接發正式料號，不必逐筆核准。
    - 試算結果有「疑似重複」警告的列不會自動核准，維持待核准；物料管理員之後逐筆開啟，確認不是重複再核准，或退回、拒絕。
    - 期初單只接受已核准的料號，所以這一步要在 §3 之前完成。
  - 不勾自動核准（或由非物料管理員上傳）時，匯入的物料都是待核准，要逐筆核准。
- [ ] **俗稱**：大家習慣的叫法，用「別名關鍵字匯入」（欄位：料號、類型、文字）加到物料上

## 3. 期初盤點（選一個停止收發料的時段，例如週末或下班後）
- [ ] 公告盤點時段：這段時間不收料、不發料
- [ ] 每個倉庫依層架盤點，抄寫以下欄位：
  - **儲位、料號、數量、批號／序號、有效期限**。
  - 空的儲位也要記下來，數量寫 0。
- [ ] 在系統「期初」→ 選倉庫 →「建立期初單」→「從 Excel 匯入明細」
  - 欄位：儲位、料號、數量、批號、序號、有效期限。
  - 料號空白表示這個儲位確認為空。
  - 一張單最多 500 行。超過時依區域分成幾張期初單。
- [ ] 建立者檢查明細後按「送出核准」
- [ ] 倉庫主管「核准並過帳」。這是庫存的第一筆紀錄。
- [ ] **抽盤驗證**：
  - 過帳後隨機抽 10～20 項，拿「庫存」查詢的數量和實物比對。
  - 有差異時找出原因（抄錯、輸入錯），用盤點或進出倉單修正。
