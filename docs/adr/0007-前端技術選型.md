# ADR-0007：前端技術選型（M0-08 量測結果）

- 狀態：**已接受（Accepted）**，使用者 2026-10-21 核准（M0-09）
- 日期：2026-10-21
- 原始數據：`poc/results/20261021-1856-full.json`；量測方法見 `docs/04-開發手冊.md` §9.1

## 背景
ADR-0005／0006 要求比較 Razor Pages 與 Blazor 靜態 SSR，硬門檻是 **Chrome 109 能完整運作**（Win7 長期支援），並以舊電腦低負載為優先。WASM 只量空白範本載入量作參考。

## 量測條件
- 開發機：AMD Ryzen 9 8940HX、32 執行緒、15.2 GB RAM、Windows 11；.NET 10.0.13；Release 發布、Production 模式。
- 瀏覽器：新版 Chromium 153.0.8010.12，以及 **Chromium 109.0.5414.0**（官方快照）。
- 以 CDP 把 CPU 節流 4 倍模擬舊電腦（閒置 CPU 與長時間記憶體兩項不節流）。**這是模擬，不是實機**；Win7 實機驗證排在 M7-11。
- 兩個 PoC 實作相同的 4 個流程（`poc/CONTRACT.md`），使用同一份 20,000 筆假資料與同一份 CSS，都不用 Bootstrap／jQuery。

## 結果

| 首次載入 DOMContentLoaded（新版／109，節流 4×） | 89／99 ms | 208／91 ms | 80／106 ms |

| 查料延遲 p50／p95（Chrome 109） | 97／110 ms | 108／118 ms | 98／103 ms |

Blazor WebAssembly 空白範本（參考）：首次載入 42 個請求、未壓縮 7.3 MB（Brotli 約 2.3 MB），在高階開發機加節流也要 1.7～2.0 秒才出現畫面。**不列入候選。**

## 解讀
1. **兩者都通過 Chrome 109 硬門檻**，查料延遲、閒置 CPU、記憶體增長都在同一量級，效能不是決定因素。
2. Blazor SSR 預設的 `blazor.web.js` 讓每台電腦第一次載入多約 47 KB（解壓後 199 KB 要解析），但之後會被快取；關閉 enhanced 後與 Razor Pages 幾乎相同。
3. **掃碼遺失與框架無關，與做法有關**：用表單送出時，伺服器回應會把輸入框清空，條碼槍已打的下一筆字元被吃掉。不論選哪個框架，掃碼都必須用 JS 佇列（`poc/Poc.RazorPages/wwwroot/js/scan.js` 的做法）。
4. Blazor enhanced 模式有兩個陷阱：回應抵達前使用者的輸入會被覆蓋，以及經 enhanced navigation 進入的頁面內 `<script>` 不執行。兩者都能處理（關閉 enhanced，或改用 `enhancedload` 事件），但會增加每個畫面的注意事項。
5. 開發上，Razor Pages 的 `name` 屬性、模型繫結、PRG、antiforgery 都是傳統表單行為，教材與除錯資料最多。Blazor SSR 實作時遇到幾個框架細節：`EditForm` 產生的欄位名稱是 `Model.X`、`NavigateTo` 的例外行為設定、`@code` 與變數名稱衝突等。

## 建議
**採用 Razor Pages＋少量原生 JS（掃碼等需要即時互動的地方用 JS 佇列）。**
- 理由：通過 Chrome 109、傳輸量與伺服器記憶體最低、沒有 enhanced 模式的陷阱，表單與 PRG 行為最直觀，最符合「使用者能自行理解與維護」的目標。
- 次選：Blazor SSR 並**關閉 enhanced navigation**，效能與 Razor Pages 相當；適合未來想用元件化寫法時再評估，但目前沒有必須的理由。

## 若核准後的後果
- `src/Warehouse.Web` 改為 Razor Pages 專案結構（`Pages/`、`_Layout`），M0-04 的 `wwwroot/index.html` 狀態頁改寫成 Razor Page。
- 掃碼共用 JS 佇列模組放在 `wwwroot/js/`，相機掃碼（M5）也輸出到同一佇列。
- `poc/` 保留作為日後效能回歸比較的參考，不併入正式程式。

## 限制與未驗證
- 所有數字來自高階開發機＋CPU 節流，不代表舊電腦的絕對秒數；Win7＋Chrome 109 實機與 4 GB RAM 電腦的實測排在 M7-11。
- 未量測網路節流（內網假設），未量測 HTTPS（M0-05）。
- Chromium 109 快照為開發版 109.0.5414.0，與 Win7 上的正式版 109.0.5414.120 可能有小差異。
