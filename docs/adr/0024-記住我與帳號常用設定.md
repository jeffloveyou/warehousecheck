# ADR-0024：「記住我」登入與跟著帳號走的常用設定（M8-06）

- 狀態：已接受（Accepted），使用者 2026-10-26 核准
- 相關：ADR-0012（登入與角色）、ADR-0017（帳號管理）、`docs/04` §3.12、`docs/11` §7.3

## 背景
使用者 2026-10-26 提出兩項需求：
- 不要每次使用都登入，登入時可以設定。
- 使用者的常用設定要記住。

原本的情況：
- 登入 Cookie 是工作階段 Cookie，關閉瀏覽器就失效。
- 明細輸入區的加入方式、欄位開關、靜音存在各裝置的 localStorage，換一台電腦或手機就要重設。

使用者的決定：
- 「記住我」的天數由系統設定調整，預設 14 天，可設 0～90 天，0 表示關閉。
- 常用設定跟著帳號走。

## 決策
1. **記住我**：
   - 登入頁有勾選框，預設不勾，並提示「公用電腦請勿勾選」。
   - 勾選時以 `isPersistent: true` 登入。`OnSigningIn` 事件把 `ExpiresUtc` 設為「現在＋N 天」，N 取自系統設定 `auth.remember_me_days`。
   - 期限會隨使用自動延長，延長的長度不變，所以連續 N 天沒使用才要重新登入。
   - 不勾選時維持原本的行為：8 小時期限、關閉瀏覽器即失效。
   - 安全機制不變：
     - security stamp 每 5 分鐘驗證一次。停用帳號、改角色、重設密碼後，持久 Cookie 最慢 5 分鐘內失效（有測試）。
     - Cookie 維持 HttpOnly、Secure、SameSite=Strict。
   - 稽核：`auth.login_success` 的 reason 欄位會記錄 `remember_me`。
   - 登出只清除這台裝置的 Cookie。
2. **常用設定**：
   - 新增資料表 `user_preferences`，主鍵 (user_id, key)。只收白名單內的鍵，值依各鍵的規則檢查（`UserPreferenceKeys`）：

     | 鍵 | 內容 |
     |---|---|
     | `scan.addMode` | 加入方式 |
     | `scan.hiddenFields` | 欄位開關 |
     | `scan.mute` | 靜音 |
     | `item.autoApprove` | 自動核准勾選（取代 M8-05 的 cookie） |
     | `documents.lastWarehouse` | 上次建單的倉庫 |

   - 讀取：版面在登入後把設定輸出為 JSON（`#wh-prefs`），不另外呼叫 API。
   - 寫入：背景 POST 到 `/Account/Preferences`，帶 antiforgery token，只能寫自己的設定。
   - 這些都只是畫面偏好。例如上次建單的倉庫，帶入前仍會檢查倉庫是否啟用、未刪除、可作業，建單時也照常檢查權限。
   - 舊資料轉移：伺服器上還沒有值、localStorage 有值的鍵，第一次載入時上傳一次。

## 後果
- 好處：
  - 現場人員不必每天重新登入。
  - 換電腦、手機也能沿用同樣的明細輸入設定。
- 風險：
  - 有人在公用電腦勾選「記住我」，下一個人就能用他的身分操作。對策如下：
    - 預設不勾，畫面有提示。
    - 系統管理員可以縮短天數，或設為 0 關閉此功能。
    - 帳號停用或重設密碼後，最慢 5 分鐘失效。
- **把天數調小或改成 0，不會讓已經記住的裝置登出。** 自動延長沿用每張 Cookie 自己原本的長度。要立刻讓某人的所有裝置失效，必須重設他的密碼或停用帳號（審查 Y1）。目前沒有「登出所有裝置」的按鈕。
- 只有用到偏好的頁面才讀取並輸出偏好，包括明細輸入、掃碼、預留，以及建單和提出物料時的伺服器端。原因是產生 antiforgery token 會讓回應變成 no-store，瀏覽器的上一頁快取就失效（審查 R3）。
- 偏好讀不到時（例如新版比 Migration 先上線），頁面照常顯示，只是沒有偏好；建單、提出物料時順手記偏好，失敗也不影響主要操作（審查 R1）。
- 共用電腦：登入後不再把偏好寫進 localStorage。舊的 localStorage 值上傳成功後就刪除，不會把前一位使用者的設定帶給下一位（審查 R2）。
- M8-05 的自動核准 cookie `wh_item_autoapprove` 不搬移：物料管理員第一次要再勾一次。舊 cookie 會自然過期，最長 1 年（審查 Y7，可接受）。
- Migration 只新增資料表，舊版不受影響（見 `docs/11` §7.3）。
