# ADR-0010：反向代理（YARP）與 A/B 切換更新

- 狀態：已接受（Accepted），M0-12 計畫經使用者核准（代理選 YARP、金鑰在 M0-12 共用、Windows 完整＋WSL 簡測）；實測 2026-10-21
- 相關：AGENTS.md 第五節、`docs/11`、ADR-0008、ADR-0009、`docs/04` §12

## 背景
AGENTS.md 要求版本更新期間正常作業盡量不中斷：先啟動新版、readiness 通過才切換新請求、舊實例排空後停止，並可回滾；不得把單機 A/B 宣稱為硬體高可用。

## 決策
1. **反向代理＝自建 `src/Warehouse.Proxy`（`Yarp.ReverseProxy` 2.3.0，MIT，微軟維護）**。
   - 理由：與主程式同一套 C#／.NET，沿用 publish、Windows 服務、systemd 腳本與 `WAREHOUSE_CONFIG_DIR`；直接使用 PFX；win-x64／linux-x64／linux-arm64 皆可。
   - 未採用：Caddy（記憶體較少，但需另學設定語言、憑證轉 PEM、非 .NET 工具鏈）；nginx（Windows 版非正式支援）；IIS ARR（只限 Windows）。
2. **切換機制＝改寫 `upstream.json`**：代理只有一個目的地 `active`，由設定目錄的 `upstream.json`（`reloadOnChange`）決定。腳本以「暫存檔＋原子置換」寫入，再**經代理確認回應版本**已是新版才算成功，逾時自動改回。舊目的地上進行中的請求照常完成。
3. **固定槽位**：A＝`WarehouseA`／`localhost:5080`、B＝`WarehouseB`／`localhost:5081`（Linux：`warehouse-a`／`warehouse-b`，埠可設定）。更新永遠裝到「待命槽位」，舊槽位停止後保留（手動啟動）供回滾。
4. **流程腳本**：`scripts/windows/switch-release.ps1`（更新／`-Rollback`）、`scripts/linux/switch-release.sh`（精簡版）。安裝失敗、冒煙失敗、代理確認逾時都不改變目前流量。每次動作寫 `deploy.log`。
5. **Data Protection 金鑰共用**（取代 ADR-0008 的 M6 待辦）：`DataProtection:KeysDirectory` 指向 `data\keys`（Linux `/var/lib/warehouse/keys`），ApplicationName 固定為 `Warehouse`；Windows 以 DPAPI（電腦層級）加密金鑰檔。A 產生的表單權杖／Cookie 切到 B 後仍有效。
6. **代理與主程式設定分離**：代理的設定目錄 `proxy-config\`（HTTPS 埠、憑證密碼、upstream.json）與含資料庫密碼的 `config\` 分開；代理服務帳號讀不到連線字串。`certs\` 只給代理帳號讀。
7. **主程式信任代理標頭**：`UseForwardedHeaders`（X-Forwarded-For／Proto，只信任 loopback），讓程式知道外部連線是 HTTPS。

## 實測（M0-12，Windows 11 開發機，32 執行緒）
| 情境 | 結果 |
|---|---|
| A→B 更新（負載 8 並行，約 1,400 次／秒） | 69,916 次請求、**0 失敗**；腳本總計 15.5 秒，代理 0.5 秒內轉到新版；版本交界前後 6 毫秒 |
| B→A 回滾（同上負載） | 56,754 次、**0 失敗**；總計 12.1 秒 |
| 故障注入：新版設定檔損壞、啟動失敗 | 腳本 6.2 秒中止、upstream 不變；同期 88,744 次全部由 A 處理、**0 失敗** |
| 三個程序同時運行 | A 工作集 116 MB／私有 50 MB、B 92／39 MB、代理 86／42 MB |
| 區網 `https://192.168.0.86:5443/` | 200，憑證鏈驗證通過 |

## 後果
- 更新會覆蓋待命槽位：更新失敗後待命槽位是壞版本，若要回到更早版本需重新部署該版本（`switch-release.ps1 -ReleasePath <舊版>`），不能用 `-Rollback`。
- 代理本身是單點：代理更新或故障時連線會中斷（代理很少需要更新，更新時需短暫維護窗口）；主機、資料庫故障亦不在保證範圍（`docs/11` §1）。
- 新版首批請求較慢（JIT、連線池），實測最大延遲約 0.6 秒；M0-13 再評估是否需要切換前預熱。
- 兩個槽位版本相同時，代理確認只能看到相同版本（腳本會警告）。
- 開發用 `--launch-profile lan` 與代理同樣使用 5443，代理服務執行時兩者不能同時使用。
- 尚未驗證：庫存寫入交易在切換時的冪等（M4 有交易後補測）、PWA 舊版快取（尚未實作 PWA）。
