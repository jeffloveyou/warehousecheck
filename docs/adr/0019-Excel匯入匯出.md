# ADR-0019：Excel 匯入與匯出（M6-03）

- 狀態：已接受（Accepted），M6 計畫經使用者 2026-10-23 核准
- 相關：FR-07、ADR-0002（低負載）、`docs/04` §23、`docs/05` T-M6-03-*、`docs/10` §4.4

## 背景
FR-07：「匯入 Excel 前有試算與錯誤明細，不能默默跳過不合法列；匯出物料與庫存清單。」使用者 2026-10-23 決定：
- 匯出 xlsx；匯入 xlsx 與 UTF-8 CSV；套件用 ClosedXML（查證授權後加入）。
- 匯入範圍：物料主檔（成為待核准）、別名與共用關鍵字、儲位、期初單明細（進草稿）。
- 有任何錯誤就整批不匯入；庫存數量只能進單據草稿，不直接改結存。

## 決策
1. **套件**：ClosedXML 0.105.0（MIT；相依 DocumentFormat.OpenXml 3.1.1 MIT、ClosedXML.Parser、ExcelNumberFormat、RBush.Signed 皆 MIT，SixLabors.Fonts 1.0.0 Apache-2.0；`dotnet list package --vulnerable` 無）。只用於**讀取**匯入檔。
2. **匯出**：自寫 `XlsxWriter`，以 `ZipArchive`（Create 模式）＋`XmlWriter` 逐列寫到暫存檔（`FileOptions.DeleteOnClose`），記憶體不隨列數增加。
   - 起因：OpenXml SDK 需要可讀寫的串流，等於把整份未壓縮工作表留在記憶體；5 萬筆、每筆 3 KB 的操作日誌峰值多約 400 MB。改寫後只多約 16 MB。
   - 文字一律 inline string（Excel 不會當公式執行）；過濾 XML 不允許的字元；單格超過 32,767 字截斷並標記；時間轉台灣時間文字。
   - 種類：物料、結存（至少一個條件）、異動（無條件時最近 30 天）、盤點明細（盲盤同畫面）、操作日誌（限系統管理員）。篩選與畫面共用同一個查詢（不會多於畫面）。
   - 上限 50,000 列（超過要求縮小條件，不截斷）；整站同時最多 `Export:MaxConcurrent` 個（預設 2，滿了回 429）。
3. **匯入**：上傳 → 試算（每列錯誤與警告）→ 確認。
   - **整批單一交易、每列 savepoint、逐列呼叫既有服務**（提出物料、新增索引、新增儲位、期初明細）：規則與畫面操作完全相同，不另寫捷徑。試算最後整筆回滾；確認時任何一列失敗也整筆回滾，並把確認時的錯誤寫回批次。
   - 為此新增 `JoinableTransaction`：上述服務在外層交易存在時加入，不自行提交（沒有外層交易時行為不變）。依賴 EF Core 的自動 savepoint；外層呼叫前不得有未儲存的追蹤變更。
   - 批次表 `import_batches`（Migration `M6_05_ImportBatches`）保存解析後的列與問題；確認以批次 ID 冪等（鎖批次列、檢查狀態）；試算 24 小時內有效；只有上傳者能確認，上傳者或系統管理員能看。
   - 權限依種類：物料 `Items.Submit`、索引 `Items.Index`、儲位 `Warehouses.Manage`、期初 `Opening.Edit`；倉庫範圍整批先檢查一次。
   - 檔案安全：≤ 5 MB（Kestrel 收取前就限制）、≤ 2,000 列、標題 ≤ 64 欄；xlsx 先檢查 zip（≤ 100 項、實際解壓 ≤ 50 MB）；公式儲存格要求「貼上值」；取 Excel 顯示的文字（保留前導零）；代碼欄被 Excel 轉成日期時列為錯誤；CSV 嚴格 UTF-8（Big5 拒絕並提示）、拒絕控制字元。
   - 整站同時只處理 `Import:MaxConcurrent` 個（預設 1）；資料庫鎖不足、死結、等鎖逾時時整批中止並回報「系統忙碌」（`import.busy`），不當成資料錯誤。
   - 新增專屬別名時的物料鎖改為 `FOR NO KEY UPDATE`：匯入期間持有到整批結束，但不擋過帳插入異動的外鍵檢查。

## 後果與限制
- 列數上限 2,000：開發機 5,000 筆物料試算 43 秒（舊主機可能超過代理 100 秒逾時，也可能用光鎖表），改為每列清除追蹤後 2,000 筆試算 7.3 秒、確認 4.6 秒。期初明細另受單據 500 行上限。
- 試算會消耗申請單號序列（`MR-` 跳號），資料正確，但稽核時要知道。
- `import_batches` 沒有保留期限與清理（`docs/09` 待辦）。
- 匯出寫到系統暫存目錄；容器部署時暫存目錄要有足夠空間。
