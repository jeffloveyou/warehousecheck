# ADR-0006：M0 開工決策與 Windows 7 相容

- 狀態：已接受（Accepted）
- 日期：2026-10-21
- 批准：使用者（產品負責人）

## 背景
M0 開工前需確定剩餘的業務預設、專案結構、工具與維運目標。另發現公司仍有 Windows 7 電腦需要使用本系統。

## 決策：業務預設
| 主題 | 決策 |
|---|---|
| D-04 必填欄位 | 固定必填：品名、分類、基本單位、追蹤模式（料號由系統產生）。品牌、原廠型號、規格、圖片可在系統設定改為必填 |
| 分類與料號前綴 | 零件 `ME`、電控 `EL`、原料 `RM`、半成品 `SF`、成品 `FG`、耗材 `CS`；流水號 6 碼（如 `EL-000125`）；可新增子分類 |
| 倉庫與儲位 | 多倉；儲位碼「倉-區-架-層-格」（如 `W1-A-01-03-02`），段數可省略、格式可設定；儲位碼在同倉內唯一 |
| 計量單位 | 內建 PCS、SET、BOX、KG、G、M、L、ROLL 等，可維護；庫存一律以基本單位記帳；料號專屬換算（如 1 BOX = 50 PCS） |
| D-26 待核出倉單 | 開啟單據審核時，送審即建立倉庫層級預留（規則見 ADR-0004） |

## 決策：專案結構與工具
| 主題 | 決策 |
|---|---|
| Repository | 程式與文件同 repo：`Warehouse.slnx`、`src/`、`tests/`、`scripts/`、`docs/` |
| 專案 | `src/Warehouse.Domain`、`Application`、`Infrastructure`、`Api`、`Web`；`tests/Warehouse.UnitTests`、`IntegrationTests` |
| Web 與 Api | **同一程序託管**：`Warehouse.Web` 為主程式，載入 `Warehouse.Api`（class library）的端點；只部署一個服務；手機／PDA 呼叫 `/api` |
| 測試框架 | xUnit v3（Apache-2.0），使用內建 Assert |
| PostgreSQL | 17 版；開發機 Windows 原生安裝 |
| Git 流程 | 功能分支 `feature/<任務ID>-<簡述>`，以 PR 合併至 `main`；`main` 保持可建置 |

## 決策：維運目標
| 主題 | 決策 |
|---|---|
| D-13 備份 | RPO 15 分鐘、RTO 4 小時：每日全備＋WAL 持續歸檔、異機備份、資料保留 7 年、每季還原演練 |
| D-23 更新相容期 | API 向後相容前一版且至少 24 小時；使用者完成當下作業後才提示更新，不強制重載；Contract 類 Migration 至少間隔一個版本 |

## 決策：Windows 7 長期完整支援（D-25）
- **前端最低相容基準：Chrome 109／Edge 109**（Windows 7 可安裝的最後版本，2023 年 1 月後無更新）。
- Win7 電腦以鍵盤打字作業、不使用掃碼槍；以「搜尋＋點選」路徑完成全部作業。
- 前端不得使用 Chrome 109 不支援的 CSS／JS 功能（例如 CSS nesting）；不使用需要較新瀏覽器的前端框架。
- 每次 UI 交付都須在 Chrome 109 實測（可在測試機安裝 Chrome 109 離線安裝檔，或使用實際 Win7 電腦）。
- M0-08 前端比較新增**硬門檻**：在 Chrome 109 上完整運作；不符合的方案直接淘汰。
- 內部 CA 根憑證需安裝到 Win7 系統憑證存放區。

### 風險與限制
- Windows 7 與 Chrome 109 已無安全更新，接在公司內網上有資安風險；**此風險由公司承擔**。建議以防火牆限制 Win7 電腦只能連本系統與必要服務。
- 長期鎖定 Chrome 109 能力，未來部分前端功能（新 CSS、新 Web API）無法使用或需要替代實作。
- Win7 端出現的瀏覽器問題，只能以調整本系統程式處理，無法升級瀏覽器修正。

## 後果
- `AGENTS.md`、`docs/10` 測試基線、`warehouse-performance` Skill 加入 Chrome 109 相容要求。
- 仍待決：D-17～D-19、D-22（NAS 型號、容器能力、A/B 資源、反向代理）及內網網域名稱，需取得硬體後決定。
